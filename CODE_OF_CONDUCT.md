# Code of Conduct

Be kind, be specific, assume good faith. Gardening traditions come from many cultures; discuss them with the same respect you would show the people who kept them. Harassment of any kind is not tolerated. Maintainers may remove comments or contributors that break this.

This is a condensed version of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
